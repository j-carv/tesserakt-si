# Tesserakt Benchmarks

## Responsibility

The planned benchmarks workstream will support reproducible reference evaluations and fair comparisons with appropriate baselines. It may use the framework but must not silently modify reference implementations. Compare total-system costs, data, compute, and quality rather than generator-only figures.

## Current state and interface

No benchmark suite, published measurements, or benchmark API is present. The initial reference reproduction and measurement protocol must be specified and recorded before results are claimed; see [IDEA.md](../../../IDEA.md) and [the plan](../../../PLAN.md).
