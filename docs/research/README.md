# Research reports

No research reports or reproduced baseline results are recorded here yet. [IDEA.md](../../IDEA.md) sets the research direction; it is not evidence that the proposed experiments have been performed.

For each investigation, add `YYYYMMDD-<slug>.md` in this directory and link it from the [documentation index](../DOCUMENTATION.md). Include YAML frontmatter (`title`, `summary`, `status`, `owners`, `updated`, `related`), the question and criteria, findings, limitations, open questions, and sources with access dates. Cite claims to verifiable sources, distinguish observations from inferences, and record conflicting evidence. For experiments, also record revisions, data and checkpoint provenance, configuration, hardware, metrics, and reproducibility limitations. Link relevant reports from the associated spec or ADR.
